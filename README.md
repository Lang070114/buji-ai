# 不急 AI — 慢慢来，比较快

> 一款不贩卖焦虑的AI伙伴。从入门到探索，三条路径，四个页面。

## 🌐 在线访问

**GitHub Pages**: https://你的用户名.github.io/buji-ai/

## 📂 页面结构

| 文件 | 内容 | 大小 |
|------|------|------|
| `index.html` | 🏠 首页入口 · 路径选择器 · AI资讯聚合 | 28KB |
| `beginner.html` | 🌱 入门 · 心态自测 · 预设场景 · 安装教程 | 64KB |
| `intermediate.html` | 🌿 进阶 · 行业模板 · 概念课堂 · 精选技巧 | 50KB |
| `advanced.html` | 🌳 探索 · 全套技巧实验室 · 自定义场景工坊 | 31KB |

## 🚀 快速部署（GitHub Pages）

1. **Fork 或创建仓库**：在 GitHub 新建仓库，命名为 `buji-ai`（或任意名称）
2. **推送代码**：
   ```bash
   git remote add origin https://github.com/你的用户名/buji-ai.git
   git add .
   git commit -m "Initial release: 不急 AI v0.5"
   git push -u origin main
   ```
3. **启用 GitHub Pages**：仓库 → Settings → Pages → Source 选 `main` 分支 → Save
4. **访问**：`https://你的用户名.github.io/buji-ai/`

## 🎨 特色功能

- **天气自适应主题**：根据访问者所在地实时天气，自动切换页面配色（晴/多云/阴/雨/雪/雾/雷暴）
- **AI资讯自动聚合**：从 TechCrunch、The Verge、36氪、机器之心 实时抓取AI资讯
- **交互式教程面板**：每个场景都是完整的分步教程（终端命令 + 概念讲解）
- **自定义场景工坊**：输入需求自动生成操作方案
- **目标全覆盖**：学生 → 职场人士，入门 → 进阶 → 探索

## 🛠️ 技术栈

- 纯前端 HTML/CSS/JavaScript（无需后端）
- Open-Meteo 免费天气 API（无需 API Key）
- RSS2JSON 资讯聚合
- 毛玻璃 UI · 响应式设计
