概念课堂 · 用场景学概念

这些词到底什么意思？

不堆术语。每个概念都绑在具体场景上讲。

💬 Prompt（提示词）

就是你跟AI说的话。好的Prompt不是「魔法咒语」。

大白话：Prompt就是你对AI说的话。好的Prompt = 说清楚你要什么 + 给上下文 + 告诉它你想要的格式。不需要背模板，只需要像跟一个很聪明但不太了解你的人在说话。

❌ 模糊的：帮我写个论文大纲

✅ 清晰的：我是一名中大经济学大一学生，正在写一篇关于「平台经济对消费者福利的影响」的课程论文，2000字左右。请先帮我列出论文大纲。
🎯 记住：第一次Prompt不需要完美，因为你可以追问。

🛠️ Skill（技能）

Claude Code里的「快捷键」——调一个命令就能完成特定任务。

大白话：Skill是Claude Code里预置好的「功能包」。比如输入/code-review，Claude Code就会自动用审查模式来工作。每个Skill背后是一套预设的指令和约束。

# 在 Claude Code 终端中直接输入：
/code-review ← 审查代码
/simplify ← 简化代码
/init ← 给项目写文档
🎯 什么时候用：当你在反复对AI说同一类话时，很可能已经有一个Skill可以直接用了。甚至可以直接问Claude「有没有可以帮我做X的Skill？」

🤖 Agent（智能代理）

不只是聊天——Agent能自己拆分任务、操作文件、执行多步骤。

大白话：普通AI聊天是你问一句它答一句。Agent不一样——你给它一个目标，它会自己：浏览文件→识别内容→逐步处理→汇总输出。它像是一个能自己动手的助手。

# 对Claude Code说：
帮我把 /papers 文件夹里所有PDF文献的参考文献提取出来，统一转成APA格式，输出到 references.md。

# Claude Code会自己：
1. 列出/papers下的文件 2. 一篇篇读取 3. 提取引用 4. 转APA格式写入文件
🎯 什么时候用：当任务需要多步骤、操作多个文件、或者需要AI自己去完成一件事而不仅仅是回答一个问题。

🌳 Worktree（工作树）

Git的高级功能——让AI在「副本」里安全地改你的文件。

大白话：Claude Code可以创建你项目的「副本」，AI在那个副本里操作。改好了、你看过了、没问题了，再把改动合并回来。如果AI改坏了，删掉副本就行。

# Claude Code 会在需要时自动创建 worktree：
git worktree add .claude/worktrees/safe-edit
🎯 你需要做什么：什么都不用做。Claude Code会在需要的时候自动使用Worktree。

📐 Context（上下文）

AI一次能「记住」多少信息——决定了它能处理多复杂的任务。

大白话：AI有一个「工作台」，上面能放的东西有限。当你一次性给它一整本教材让它背时，可能超出工作台容量，它就会「忘记」前面的东西。

# 不同工具的上下文容量类比：
ChatGPT ≈ 能同时记住一本中篇小说
Claude Code ≈ 能同时记住三本教材 + 整本代码
🎯 什么时候需要关注：当你发现AI「忘记了」你之前说过的重要信息时。解决方案：分段对话、用文件存储关键信息、用Agent。

👥 Subagent（子代理）

Claude Code可以「分身」出多个小助手同时干活。

大白话：当任务很大时，Claude Code可以派出多个「子代理」同时工作。比如你要整理20篇文献，它可以同时派出5个子代理每人处理4篇，处理完后汇总。

# 你对Claude Code说的话：
帮我把这20篇文献分成5组，同时处理。每组提取参考文献并转APA格式。
🎯 什么时候用：不需要你手动调用。当Claude Code判断任务适合并行处理时，它会自动使用子代理。

链式任务

Agent A读文件提取数据 → Agent B分析数据 → Agent C写报告

怎么做：在Claude Code中分步执行——第一步提取数据到中间文件；第二步分析中间文件；第三步基于分析写报告。Claude Code会自动记住上下文。

# 第一步：
扫描/papers文件夹中所有PDF，提取每篇的作者、年份、方法、结论，汇总到 analysis-data.md

# 第二步（同一对话继续）：
分析 analysis-data.md 中的数据——哪种方法最常用？样本量分布如何？

# 第三步：
基于前面的分析，写一份文献综述报告。
🎯 什么时候用：系统性文献综述、多步骤数据分析、处理大任务时保护上下文。
📋

格式炼金术

一段口语录音→同时出：会议纪要/邮件/PPT/飞书文档/Notion

怎么做：把一段原始内容喂给AI，要求它同时输出多种格式。AI会根据不同格式的特点调整内容组织方式。

# 对Claude Code说：
以下是我们的产品讨论记录。请同时转换为5种格式：
1. 📝 标准会议纪要（含待办/负责人/DDL）
2. 📧 给全组的邮件通报
3. 📊 PPT大纲（5页以内）
4. 📄 飞书文档格式
5. 🗂️ Notion页面
🎯 什么时候用：开完会需通知不同渠道、一个内容需在多个平台分发。

自定义Skill模板

把常用工作流封装成可复用命令，一句话触发

怎么做：在项目根目录创建CLAUDE.md文件，写入常用指令模板。之后每次启动Claude Code，它都会自动读取这个文件。

# 在项目根目录创建 CLAUDE.md：
# 每周报告模板
当我输入「/周报」时，请：
1. 读取docs/本周工作目录下的所有文件
2. 按「完成」「进行中」「计划」「风险」汇总
3. 输出到reports/周报_YYYY-MM-DD.md

# 之后只需说「/周报」即可触发整个流程
🎯 什么时候用：每周重复的工作、有固定格式要求的任务、需要统一团队工作流。
