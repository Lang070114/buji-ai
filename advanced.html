多角色辩论

3个不同人设的AI互相辩论，你来裁判

怎么做：在Claude Code中连续设定三个角色，分别对同一问题发表观点。然后把三种观点汇总，让AI做交叉辩论，找出各自逻辑中的矛盾点。

# 对Claude Code说：
请依次以三个不同角色的视角分析这个政策议题：
1. 自由市场经济学家
2. 主张产业保护的政策制定者
3. 关注就业的社会学家
分析完成后，作为第四方指出三个观点的核心分歧和逻辑漏洞。
🎯 什么时候用：准备辩论赛、商赛答辩预判评委会问题、写论文讨论部分、做决策前避免确认偏误。
🔗

链式任务

Agent A提取数据→Agent B分析→Agent C写报告

怎么做：在Claude Code中分步——第一步扫描文件提取数据到中间文件；第二步分析中间文件；第三步基于分析写报告。每一步的输出是下一步的输入。

# 第一步：提取
扫描/papers所有PDF，提取作者、年份、方法、结论→汇总到 analysis-data.md

# 第二步：分析
分析 analysis-data.md——哪种方法最常用？结论有没有趋势变化？

# 第三步：报告
基于分析写文献综述报告。
🎯 什么时候用：系统性文献综述、多步骤数据分析、保护上下文不溢出。
🧹

「这不合理」检查

把AI初稿再给另一个AI，专门挑逻辑漏洞和数据错误

怎么做：开启新对话，告诉AI：「你现在是严格的质量审查员。逐条检查以下内容中的逻辑漏洞、数据不一致、以及未经证实的假设。标注严重程度。」然后粘贴AI初稿。

# 在Claude Code新对话中：
你现在是严格的质量审查员。逐条检查以下报告中的：
- 逻辑漏洞（因果倒置、以偏概全）
- 数据不一致（两处引用了不同数字）
- 未经证实的假设
标注严重程度：🔴致命/🟡需注意/🟢小问题

[粘贴AI初稿]
🎯 什么时候用：提交论文前、发重要邮件前、写竞赛方案后——用AI弥补AI缺陷。

自定义Skill模板

把常用工作流封装成可复用命令，一句话触发

怎么做：在项目根目录创建CLAUDE.md文件，写入常用指令模板。每次启动Claude Code会自动读取。

# 在项目根目录创建 CLAUDE.md：
# 每周报告模板
当我输入「/周报」时，请：
1. 读取docs/本周工作目录
2. 按「完成」「进行中」「计划」「风险」汇总
3. 输出到reports/周报_YYYY-MM-DD.md
🎯 什么时候用：每周重复工作、有固定格式要求的任务、统一团队工作流。
📋

格式炼金术

一段口语录音→同时出：纪要/邮件/PPT/飞书文档/Notion

怎么做：把原始内容喂给AI，要求同时输出多种格式。AI会根据不同格式特点调整组织方式。

# 对Claude Code说：
以下是产品讨论记录。请同时转换为5种格式：
1. 📝 会议纪要（含待办/负责人/DDL）
2. 📧 给全组的邮件通报
3. 📊 PPT大纲（5页以内）
4. 📄 飞书文档格式
5. 🗂️ Notion页面

[粘贴原始记录]
🎯 什么时候用：一个内容需在多个平台分发、开完会需同时通知不同渠道。
🎛️

多模型对比

同一任务给不同模型做，找最适合你场景的工具

怎么做：准备标准化测试任务，分别在ChatGPT、Claude.ai、Claude Code中运行。对比：① 输出质量 ② 需要多少追问 ③ 是否理解专业背景。你会发现不同工具各有擅长。

# 标准化测试（三工具分别跑）：
我是经济学学生。以下是我的课堂笔记：

「讲了菲利普斯曲线，通胀和失业率有trade-off。短期向下倾斜，长期垂直——因为人们会调整通胀预期。还提到了卢卡斯批判...」

请整理成结构化笔记：
1. 核心概念（每概念一句话定义）
2. 概念间逻辑关系（箭头表示）
3. 可能的考点
4. 还需补充什么背景知识？
🎯 什么时候用：不确定哪个工具更适合时、评估AI能力边界时、团队选型前做对比。
